## 1. Project Overview

**Sudarshan Compiler Studio** is an interactive, browser-based compiler laboratory and development environment built around the **Sudarshan** programming language (MiniLang).

It combines:
1. **Core Handwritten Compiler & Virtual Machine (Python 3)**: A 5-phase compiler pipeline featuring a DFA scanner, recursive-descent LL(1) parser, lexically-scoped symbol table with block shadowing, Three-Address Code (TAC) intermediate representation generator, multi-pass optimizer (constant folding, algebraic simplification, and dead-code elimination), and an instruction-level Virtual Machine interpreter.
2. **Dedicated REST API (FastAPI & Pydantic)**: A programmatic service providing structured JSON serialization of every compiler phase, deterministic execution timeouts, and infinite-loop step limits.
3. **Interactive Web IDE (React, TypeScript, Vite & Monaco Editor)**: A dark-themed compiler workbench inspired by modern compiler laboratories (such as MiniLLVM), enabling developers and students to write Sudarshan code, inspect internal compiler phases, analyze optimization transformations step-by-step, and execute programs directly in the browser.

Every output displayed in the Studio is generated by the **real compiler pipeline**—never fabricated or simulated with mock data.

## 2. Key Features & Innovations

### Core Compiler & VM
- **Zero-Dependency 100% Handwritten Architecture**: Scanner, LL(1) parser, scoped symbol table, TAC IR generator, optimizer passes, and VM interpreter are built strictly with Python standard library.
- **Multi-Pass Constant Folding & Propagation**: Simplifies compile-time arithmetic (`2 + 3 * 4` $\rightarrow$ `14`) and comparison expressions dynamically while preserving runtime exceptions like division-by-zero.
- **Algebraic Identity Simplification**: Automatically reduces identity operations (`x + 0` $\rightarrow$ `x`, `x * 1` $\rightarrow$ `x`, `x - x` $\rightarrow$ `0`, `x * 0` $\rightarrow$ `0`, `x / 1` $\rightarrow$ `x`, `x == x` $\rightarrow$ `1`).
- **Static Branch Pruning & Dead Code Elimination**: Simplifies constant conditional jumps (`IF_FALSE 0 GOTO L1` $\rightarrow$ `JUMP L1`, `IF_FALSE 1 GOTO L1` $\rightarrow$ omitted) and strips unreachable quadruples following unconditional jumps.
- **Scope Mangling for Flat Register Allocation**: Solves variable shadowing in linear TAC by appending scope depth suffixes (`x_s1`), preserving lexical block isolation without runtime stack frame overhead.
- **Infinite-Loop Step Limit Protection**: VM execution implements a configurable step threshold (`max_steps=100000`) preventing infinite loops from hanging the runtime.

### Interactive Compiler Studio (Web IDE)
- **Monaco Code Editor**: Full-featured code editor with custom Sudarshan syntax highlighting, line numbers, bracket matching, and compile-time error squiggles placed at exact line and column coordinates.
- **8-Stage Compiler Pipeline Inspection**:
  1. **Tokens**: Interactive token stream table with live search and category filtering.
  2. **AST**: Interactive collapsible tree visualizer, indented hierarchy text view, and Graphviz DOT graph export.
  3. **Symbol Table**: Scoped variable tables, nesting depth indicators, and variable declaration locations.
  4. **Semantic Analysis**: Static semantic diagnostics with rule-by-rule verification badges.
  5. **Raw TAC**: Unoptimized Three-Address Code quadruples with line numbers and copy action.
  6. **Optimized TAC**: Side-by-side comparative diff with instruction count reduction metrics.
  7. **Optimization Analysis**: Concrete transformation report detailing every optimization pass, original instruction, transformed instruction, and compiler rationale.
  8. **Program Output**: Simulated terminal console displaying runtime standard output, VM step count, execution time in milliseconds, and exit status.

## 3. Compiler Pipeline Architecture

```text
                  Source Code (.mini)
                           │
                           ▼
Phase 1: Lexical Analyzer (src/lexer.py & src/errors.py) ──► Token Stream (Line & Col tracking)
                           │
                           ▼
Phase 2: Syntax Analyzer (src/parser.py & src/ast_nodes.py) ──► Abstract Syntax Tree (AST)
                           │
                           ▼
Phase 3: Semantic Analyzer (src/semantic.py & src/symbol_table.py) ──► Scoped Symbol Table
                           │
                           ▼
Phase 4: Intermediate Code Generator (src/tac.py) ──► Three-Address Code (Quadruples)
                           │
                           ▼
Phase 4b: TAC Optimizer Pass (src/tac_opt.py) ──► Constant Folding, Algebraic & DCE
                           │
                           ▼
Phase 5: Virtual Machine Interpreter (src/interpreter.py) ──► Code Execution & Output
```

## 4. Sudarshan Formal Grammar (BNF Syntax)

```ebnf
program    -> statement*
statement  -> varDecl | assign | printStmt | ifStmt | whileStmt | block
varDecl    -> 'int' ID '=' expr ';'
assign     -> ID '=' expr ';'
printStmt  -> 'print' '(' expr ')' ';'
ifStmt     -> 'if' '(' expr ')' block ('else' (ifStmt | block))?
whileStmt  -> 'while' '(' expr ')' block
block      -> '{' statement* '}'
expr       -> comparison
comparison -> addExpr (('==' | '!=' | '<' | '>' | '<=' | '>=') addExpr)*
addExpr    -> term (('+' | '-') term)*
term       -> factor (('*' | '/') factor)*
factor     -> NUMBER | ID | '(' expr ')' | '-' factor
```

## 7. How to Run Locally

### Prerequisites
- Python 3.10 or higher (Zero Node.js dependency required)

### Quick Start: Launch Studio with One Command
```bash
# 1. Create Python virtual environment and install packages
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 2. Launch Compiler Studio
./start_studio.sh
```
Open **[http://localhost:8000](http://localhost:8000)** in your browser to access Sudarshan Compiler Studio.

---

### Running Manually

```bash
source .venv/bin/activate
uvicorn api.index:app --host 127.0.0.1 --port 8000 --reload
```
- Studio Playground: `http://127.0.0.1:8000`
- API Documentation: `http://127.0.0.1:8000/docs`

---

### Running the Command-Line Interface (CLI)

The CLI driver remains fully intact and backward-compatible:
```bash
# Run program execution
./sudarshan examples/valid.mini

# Inspect all compiler phases
./sudarshan examples/valid.mini --all

# Educational phase-by-phase explanation
./sudarshan examples/valid.mini --explain

# Inspect specific phases
./sudarshan examples/valid.mini --tokens --ast --tac --opt
```

## 8. Backend API Reference

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/health` | Health status and supported compiler phases |
| `GET` | `/api/examples` | Curated Sudarshan example programs with metadata |
| `POST` | `/api/compile` | Compiles source code through all stages up to optimization |
| `POST` | `/api/compile-run` | Compiles code and executes the program in the Virtual Machine |
| `POST` | `/api/run` | Executes provided source code or TAC in the Virtual Machine |

### Example Compilation Request:
```bash
curl -X POST http://127.0.0.1:8000/api/compile-run \
  -H "Content-Type: application/json" \
  -d '{"source_code": "int x = 2 + 3 * 4;\nprint(x);", "optimize": true}'
```

## 11. Known Limitations & Scope

- **Data Types**: The Sudarshan programming language is intentionally scoped to 32/64-bit integer arithmetic (`int`). Floating-point arithmetic, strings, and arrays are not part of the language specification.
- **Functions & Procedures**: Functions are not included in the baseline BNF grammar; control flow is structured around statements, blocks, `if/else`, and `while` loops.
- **Target Architecture**: Sudarshan compiles to Three-Address Code (TAC) quadruples executed on a Von Neumann register VM. It does not target native assembly or LLVM bitcode.
